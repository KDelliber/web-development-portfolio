Linux Systems Administration

This project summarizes Linux coursework completed in Fedora virtual machines. It demonstrates foundational command-line and system-administration practice relevant to infrastructure support. It is academic lab experience, not professional Linux administration employment.

Lab Environment

I used Fedora virtual machines in an isolated training environment, working from both the graphical interface and command-line terminals. This allowed administrative changes to be practiced and verified without affecting a production system.

User and Group Administration

  • Reviewed local account information in /etc/passwd and protected account data in /etc/shadow.
  • Created, modified, locked, unlocked, and removed local user accounts.
  • Created and managed groups and verified account membership.
  • Checked the effect of account changes instead of assuming that a command completed the full task.

File Ownership and Permissions

The labs reinforced the relationship between users, groups, file ownership, and access. I practiced examining directory ownership and using administrative commands carefully, particularly when removing accounts or changing access.

Working Method

  1. Inspect: Review the existing user, group, file, or directory state.
  2. Change: Apply one deliberate administrative command.
  3. Verify: Recheck the relevant account database, group membership, ownership, or access.
  4. Document: Record the command, expected result, and observed result.

Skills Demonstrated

  • Fedora Linux and virtual machines
  • Command-line navigation and administration
  • Local users, groups, and account controls
  • File ownership and permissions fundamentals
  • Verification-focused change management
