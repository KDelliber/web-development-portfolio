Windows Server Administration

This project summarizes Windows Server coursework completed in a controlled virtual lab. It demonstrates practical systems-administration training rather than professional employment experience.

Lab Environment

Windows Server 2016 was installed and configured in Oracle VirtualBox. The isolated environment allowed server and client settings to be changed, tested, and documented without affecting a production network.

  • Windows Server 2016 virtual machines
  • Windows client virtual machines
  • Private virtual networking
  • Server Manager and Windows administration tools

Work Completed

  • Created virtual machines and installed Windows Server with Desktop Experience.
  • Completed post-installation tasks including time zone, computer naming, static IP configuration, and update settings.
  • Practiced server networking and communication between virtual systems.
  • Worked with user accounts, groups, Active Directory objects, and access permissions.
  • Documented completed activities with lab answer sheets and screenshots.

Administration Method

  1. Prepare: Confirm the VM, network mode, storage, and installation media.
  2. Configure: Apply one planned server or account change at a time.
  3. Verify: Confirm the expected setting, access, or connectivity result.
  4. Document: Record the completed task and retain supporting screenshots.

Evidence and Scope

The original coursework contains completed lab sheets and screenshots from the Windows Server environment. This page presents the relevant skills in a concise employer-friendly format; it does not claim that the work was performed on a live company domain.

Skills Demonstrated

  • Windows Server installation and post-installation configuration
  • Virtual-machine deployment and isolated lab networking
  • Static IPv4 configuration and computer naming
  • Active Directory, user, group, and permissions fundamentals
  • Change verification and technical documentation
