Project Overview

This project involved building a versatile home PC for gaming, productivity, and future tasks. The client had specific preferences for components, with a focus on brand loyalty to Corsair products. The final cost was slightly over the $2,000 budget but met all performance requirements.

Detailed Write-Up

A detailed report describing the entire build process, from component selection to assembly and testing, is available for download:

Equipment Used

  • Case: Corsair 4000D
  • Graphics Card: NVIDIA RTX 3060
  • Power Supply: Corsair RM850
  • Motherboard: Z690 AX
  • Storage: WD Black SN850X NVMe SSD
  • RAM: Corsair Vengeance LPX DDR4 2x16GB
  • CPU Cooler: DeepCool AK620
  • Processor: Intel Core i7-11700K

Steps Taken

  1. Planning: Defined the requirements and selected components accordingly.
  2. Purchasing: Ordered components based on client preference and budget.
  3. Assembly: Assembled components in the Corsair 4000D case and installed all necessary software and drivers.
  4. Testing: Verified system stability and performance with benchmarks.

Challenges and Solutions

  • Challenge: Ensuring compatibility between all components.
    Solution: Used PC Part Picker to confirm component compatibility and power sufficiency.
  • Challenge: Managing tight space in the case for optimal airflow.
    Solution: Strategically placed components to ensure efficient cooling.

Outcome

The PC build was successful, delivering excellent gaming performance and efficiency for work-related tasks. The client was satisfied with the result and the system is expected to handle future workloads effectively.

Skills Demonstrated

  • Component Selection and Compatibility Checking
  • System Assembly and Configuration
  • Performance Testing and Optimization
