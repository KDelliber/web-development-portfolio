PowerShell Support Toolkit

A small collection of practical PowerShell scripts for workstation support, diagnostics, and repeatable troubleshooting.

Project Goal

The toolkit focuses on common support tasks that benefit from automation: gathering system details, checking network configuration, reviewing disk capacity, validating services, and surfacing recent Windows errors. The scripts are intentionally short and readable so each command can be understood and explained.
