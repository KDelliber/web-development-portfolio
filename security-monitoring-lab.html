Windows Security Monitoring

This case study combines related security coursework into one practical workflow: reduce unnecessary exposure, inspect Windows events, focus recurring investigations, and use monitoring data to identify activity that deserves attention. It represents academic lab training, not professional security-employment experience.

Windows Firewall Configuration

I reviewed Windows Firewall settings for private and public networks and practiced applying more restrictive protection to public-network connections. The lab reinforced that firewall changes should match the network profile and required business access rather than disabling protection to solve connectivity problems.

Event Viewer Investigation

  • Opened Windows Event Viewer and reviewed Windows log categories.
  • Examined event severity, source, timestamps, and event details.
  • Created a custom view to narrow a large event history to relevant records.
  • Used filtered results as a repeatable starting point for troubleshooting and escalation.

Introductory SIEM Monitoring

A GlassWire lab introduced security-information and event-monitoring concepts through network activity, application communication, alerts, and firewall visibility. The exercise connected endpoint observations with the broader idea of collecting and reviewing security-relevant events.

Security Workflow

  1. Establish scope: Identify the affected system, user, network profile, and reported impact.
  2. Review controls: Confirm firewall status and required connectivity.
  3. Inspect evidence: Review relevant logs, sources, timestamps, and event details.
  4. Filter: Build a focused view that can be reused during investigation.
  5. Verify and document: Retest expected access and record findings before resolving or escalating.

Skills Demonstrated

  • Windows Firewall and network-profile awareness
  • Windows Event Viewer navigation and log interpretation
  • Custom event filtering
  • Basic SIEM and endpoint-monitoring concepts
  • Evidence-based troubleshooting and escalation documentation
