Cloud Infrastructure and Security

This project summarizes AWS coursework covering virtual compute, networking, and identity controls. The resources were created for academic training and do not represent administration of a production company environment.

EC2 Virtual Machine Deployment

I used the AWS Management Console to launch and review EC2 instances, including a Windows Server image. The exercises covered image and instance-type selection, configuration options, addressing, and the difference between private and public reachability.

Virtual Networking and Security

  • Reviewed virtual private cloud resources and subnet relationships.
  • Examined inbound and outbound network ACL rules.
  • Reviewed security-group rules and their relationship to services such as Windows Remote Desktop on TCP port 3389.
  • Compared public and private IP addressing when evaluating how an instance could be reached.

Identity and Access Management

  • Created an AWS IAM user for controlled lab testing.
  • Reviewed and applied permissions to test different access levels.
  • Configured account password-policy requirements.
  • Connected cloud permissions to least-privilege and identity-management concepts.

Deployment and Verification Method

  1. Plan: Identify the workload, operating system, network, and required access.
  2. Deploy: Select the instance and apply the intended configuration.
  3. Restrict: Review network and identity permissions before enabling access.
  4. Verify: Confirm addressing, allowed traffic, and the effective user permissions.
  5. Document: Record the configuration and remove or stop unneeded training resources.

Skills Demonstrated

  • AWS Management Console and EC2 fundamentals
  • Virtual machines and cloud addressing
  • VPC, subnet, security-group, and network ACL concepts
  • IAM users, password policies, and permissions
  • Least-privilege and cloud-security fundamentals
